23// Creates a buffer and backs it with freshly allocated memory. Returns false and
24// leaves the handles at VK_NULL_HANDLE on failure.
25//
26// preferred names memory the caller would rather have; when no memory type offers
27// it the allocation falls back to properties, which is what it must have. It exists
28// for buffers the CPU writes and the GPU reads every frame: on a device that
29// exposes device local memory as host visible those belong there rather than in
30// system RAM, which the GPU can only reach across the bus.
