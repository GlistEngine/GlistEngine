# Bitmap Font Sample

This sample demonstrates how to load a pre-rendered glyph atlas with
`gBitmapFont`, map UTF-8 characters to atlas coordinates, and draw multiline
text with custom scale, letter spacing, and line height.

- Up arrow: increase font scale
- Down arrow: decrease font scale

The atlas contains `A-Z` and `0-9` in a 6-by-6 grid. Each glyph occupies a
209-by-209 pixel cell.
