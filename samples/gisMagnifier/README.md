# gMagnifier Sample

An interactive sample demonstrating the `gMagnifier` GLSL post-process effect in GlistEngine.

The sample magnifies a circular area around the mouse position. A transparent magnifying-glass frame is drawn over the processed region, while a detailed technical background makes the magnification easy to observe.

## Demo

The demonstration video shows the magnified region following the mouse across the background and the GlistEngine logo.

## Features

* Magnifies a circular region around the mouse position.
* Supports configurable radius, zoom amount and edge softness.
* Updates continuously with mouse dragging and movement.
* Supports touch position updates.
* Keeps the magnifying-glass frame aligned with the processed region.
* Uses a detailed background to make magnification clearly visible.

## Controls

| Input               | Action                     |
| ------------------- | -------------------------- |
| Move the mouse      | Move the magnifying glass  |
| Drag the mouse      | Move the magnifying glass  |
| Touch or drag       | Move it on touch devices   |
